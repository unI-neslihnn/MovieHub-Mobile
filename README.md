<h2>🎬 MovieHub</h2>

MovieHub, kullanıcıların vizyondaki ve popüler filmleri, dizileri keşfetmesini, fragmanlarını izlemesini, arama yapmasını, favorilerine eklemesini ve izlenecekler listesi oluşturmasını sağlayan React Native ve Expo tabanlı bir mobil sinema ve dizi keşif uygulamasıdır.
Uygulama canlı verilerini TMDB (The Movie Database) API üzerinden almaktadır.

<h3>📌 Özellikler</h3>

- Film ve Dizi Keşfi: Trend filmleri, popüler dizileri ve farklı türlerdeki (Aksiyon, Komedi, Bilim Kurgu vb.) içerikleri listeleme.
- Yanal Sonsuz Kaydırma: Kategorilere özel yatay liste mimarisi ile dinamik sayfalama ve veri yükleme.
- Çoklu Arama: Film, dizi ve oyuncuları anlık olarak arama ve sonuçları kategorize etme.
- Fragman İzleme: Film ve dizi detay ekranında YouTube entegrasyonu ile resmi fragmanları oynatma.
- Favori Yönetimi: Beğenilen filmleri favorilere ekleme ve cihaz hafızasında saklama.
- İzlenecekler Listesi: Daha sonra izlenmek istenen içerikleri liste oluşturarak kaydetme.
- Oyuncu ve Detay Bilgisi: İçeriklere ait özet, IMDb puanı, yayın tarihi ve oyuncu kadrosunu görüntüleme.
- Şık Karşılama ve Tema: Marvel / Netflix esintili modern koyu tema ve özel karşılama ekranı.

<h3>⚙️ Kullanılan Teknolojiler</h3>

- React Native ve Expo SDK
- React Navigation (Stack ve Tab Navigation)
- TMDB (The Movie Database) API
- Axios
- AsyncStorage
- react-native-youtube-iframe
- Expo Vector Icons
